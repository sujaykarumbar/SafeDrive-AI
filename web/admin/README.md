# SafeDrive AI — Admin & Security Audit Panel

## Overview
Administrative portal for system health monitoring, user role distribution, and immutable security audit inspection.

## Features
- **System Health Monitor**: Live gateway and database connectivity.
- **Aggregate Analytics**: User count by role, active trips, cumulative hazards and emergencies.
- **Security Audit Trail**: Immutable table logging logins, trip creation, emergency escalations, and hazard status changes.

## Running Locally
In the `web/` directory:
```bash
npm install
npm run dev
```
Select "Admin & Audit".
