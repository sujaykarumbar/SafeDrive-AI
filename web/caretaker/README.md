# SafeDrive AI — Caretaker Web Dashboard

## Overview
The Caretaker Dashboard provides consent-based live trip monitoring for parents, family members, and guardians.

## Features
- **Live Fleet Map**: Real-time position tracking of authorized drivers with speed tooltips and pulsating status rings.
- **Safety Status Gauges**: Real-time indicators (Normal, Warning, Emergency, Idle).
- **Explainable Risk Summaries**: Factor breakdown (e.g. night driving after 11 PM, sudden braking spikes).
- **Emergency Center**: Critical alert banner with 1-click acknowledgment and emergency contact integration.
- **Trip Replay**: Historic path trajectory playback with driving event markers.

## Running Locally
In the `web/` directory:
```bash
npm install
npm run dev
```
Open `http://localhost:5173` and select "Caretaker Fleet".
